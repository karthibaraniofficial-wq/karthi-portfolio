- **Framework:** React 19 + TypeScript (Strict)

- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`) + Custom Design Tokens
- **Motion & Interactions:** Framer Motion
- **Icons:** Lucide React + Custom SVG Icons
- **Effects:** Canvas Confetti + Web Audio API (Muted by default)

## 📦 Getting Started

### Prerequisites

- Node.js `v20+` or `v24+`
- npm `v10+`

### Installation

```bash
git clone https://github.com/karthibaraniofficial-wq/karthi-portfolio.git
cd karthi-portfolio
npm install
```

### Development Server

```bash
npm run dev
```

Visit [http://127.0.0.1:5173/](http://127.0.0.1:5173/) in your browser.

### Production Build

```bash
npm run build
npm run preview
```

## 📜 Architecture Standards

Every feature adheres to strict engineering rules:
- **Zero-any policy:** Strictly typed TypeScript contracts.
- **Deterministic verification:** Real observable states without fake or AI-generated illusions.
- **Accessible design:** Semantic markup, visible focus indicators, and support for `prefers-reduced-motion`.
- **Performance budget:** Fast initial load, zero bloated 3D dependencies, clean code splitting.
